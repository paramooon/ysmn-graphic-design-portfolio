# YSMN — Graphic Designer Portfolio

Динамичный одностраничный сайт-портфолио графического дизайнера YSMN.

## Особенности

- выразительная типографика и авторские постеры на CSS;
- плавные scroll-reveal анимации и интерактивный курсор;
- адаптивная верстка для desktop и mobile;
- доступная навигация и поддержка `prefers-reduced-motion`;
- без сборщика и зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Настройка

Замените тексты проектов, email и контактные данные в `index.html`. Палитра задаётся CSS-переменными в начале `styles.css`.
